# BLE Adv Test

Fixed manufacturer-specific advertisement test for Official Firmware 1.4.3.
Press OK to start/stop the 200 ms beacon, Back to stop and exit.
The legacy spam features are excluded from this branch's FAP.
Validated on OFW 1.4.3: 100 Start/Stop cycles, 10 exits/reopens during advertising
and fixed payload reception. Existing screenshots show the original app.
